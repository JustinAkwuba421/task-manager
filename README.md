# Task Manager

A simple task manager built with plain HTML, CSS, and JavaScript. Use it to keep track of everyday tasks, mark them complete, and filter the list to focus on what you need.

Tasks are saved in your browser’s local storage, so they remain available after you refresh the page in the same browser.

## Features

- Add tasks
- Double-click a task’s text to edit it
- Mark tasks complete with a checkbox
- Delete individual tasks
- Filter tasks by **All**, **Active**, or **Completed**
- Clear all completed tasks at once
- See how many tasks are left
- Save tasks in the browser using `localStorage`
- Responsive layout for smaller screens

## Tech stack

- **HTML** — page structure
- **CSS** — layout and styling
- **JavaScript** — task interactions and local storage

No frameworks or build tools are required.
